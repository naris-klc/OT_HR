# แถบเปลี่ยนหน้าใต้ตาราง คิวรออนุมัติ — สิ่งที่ถามและสิ่งที่ตกลงกัน

**ขอมาเมื่อ 2026-09-11 เป็นประโยคเดียว:** *"ตารางหน้า รออนุมัติ OT เพิ่ม
pagination รูปแบบเดียวกับที่ app ใช้อยู่แล้ว"*

เอกสารนี้บันทึก**ดีไซน์ที่ตกลงกันก่อนเขียนโค้ด** ตาม AGENTS.md §จอใหม่ไม่ได้เริ่ม
จากศูนย์ · เหตุผลเชิงกลไกและตัวเลขทั้งหมดอยู่ใน README §แถบเปลี่ยนหน้าเดียวทั้งแอป
เอกสารนี้เก็บเฉพาะ**คำถามที่ถาม คำตอบที่ได้ และทางที่ไม่ได้เลือก**

## 0. ของที่มีอยู่แล้ว และสิ่งที่แปลว่าไม่ต้องออกแบบ

*"รูปแบบเดียวกับที่ app ใช้อยู่แล้ว"* แปลตรงตัวว่า **ห้ามสร้างแถบที่สอง**

| มีอยู่แล้ว | ที่ | ใช้ซ้ำได้เลย |
|---|---|---|
| `TablePager` | `components/common.jsx` | ✅ ทั้งตัว |
| `usePageReset` | `components/common.jsx` | ✅ |
| `PAGE_SIZES` = 10 · 20 · 50 · 100 | `components/common.jsx` | ✅ ไม่ส่ง `sizes` ทับ |
| CSS ของแถบ + บล็อก 560px | `app/styles.css` (`.table-pager`) | ✅ เพิ่มเฉพาะระยะขอบของจอนี้ |
| ตัวอย่างการตัดหน้าในเบราว์เซอร์ | `components/AdminView.jsx` (ประวัติเวอร์ชันนโยบาย) | ✅ ลอกรูปทรง |
| ตัวอย่าง `goPage` ที่เลื่อนจอ | `components/HrView.jsx` | ✅ ลอกรูปทรง |

**สิ่งที่ไม่ต้องใช้:** `useKeptFetch` — จอนี้ถือแถวไว้ครบในมือแล้ว (คิวมาทั้งก้อน
เพดาน `MAX_LIST_LIMIT` และปุ่ม โหลดทั้งหมด คือสิ่งที่ยกเพดานนั้น) การตัดหน้าจึงเป็น
`slice` ที่เกิดทันที ไม่มีคำขอใหม่ ไม่มีสถานะ `.is-paged`

## 1. คำถามรอบแรก และคำตอบ

| ถาม | ตอบ |
|---|---|
| ขึ้นแท็บไหนบ้าง | **ทั้ง 4 แท็บ** ที่ `ApprovalQueue` วาด |
| ติ๊กไว้แล้วพลิกหน้า ติ๊กหายไหม | **ไม่หาย — ติ๊กอยู่ข้ามหน้า** |
| เริ่มที่กี่แถวต่อหน้า | **20** |

**ทั้ง 4 แท็บมาพร้อมกันโดยไม่ต้องเลือก** เพราะ รออนุมัติ OT · รออนุมัติ ·
รออนุมัติแทน · ใบที่ยังไม่มีใครเซ็น เป็นคอมโพเนนต์ตัวเดียวกันที่
`components/App.jsx` เรียกด้วยพร็อพต่างกัน (`stage` · `delegatedOnly` ·
`unsignedOnly`) การเลือกทำแค่แท็บเดียวคือการเขียนเงื่อนไขเพิ่มเพื่อ**ไม่**ทำ

| ถาม | ตอบ |

คือการเริ่มอ่านตรงกลางรายการ

## 3. ทางที่ไม่ได้เลือก

**ไม่ตัดหน้าที่เซิร์ฟเวอร์** เหมือนตารางบันทึกจราจร · เราต์ส่งคิวมาทั้งก้อนอยู่แล้ว
และสิ่งที่คิดจากก้อนนั้นทั้งก้อนมีหลายอย่าง — `actionable`, ยอดชั่วโมงของสิ่งที่
ติ๊กไว้, ประโยคที่บอกว่าตัวกรองซ่อนกี่ใบ · สอนให้มัน `skip` คือทำให้ตัวเลขเหล่านั้น
กลายเป็นตัวเลขของหน้าปัจจุบัน ซึ่งคือกฎ **A PAGE IS NOT A FILTER** ที่ถูกละเมิด

**ไม่ทำแถบคนละตัวสำหรับมือถือ** อย่างที่ `HrView` มี (`.pager-row` ที่อยู่ใน
`<tbody>`) · จอนี้ไม่ต้องการ เพราะใต้ 860px มันเปลี่ยน `<tr>` ชุดเดิมให้เป็นการ์ด
ด้วย CSS ตารางยังเป็นตารางเดิม แถบใต้ตารางจึงเป็นแถบเดียวกันทั้งสองความกว้าง

**ไม่เพิ่ม CSS ของแถบเอง** นอกจากระยะขอบซ้าย/ขวา/ล่าง ที่จำเป็นเพราะการ์ดของจอนี้
เป็น `.card.flush` ซึ่ง `padding: 0` · รูปทรง สี ขนาดปุ่ม การซ้อนกันที่ 560px
มาจาก `.table-pager` เดิมทั้งหมด
