> **รายการนี้ปุ่มหายไปไหน**

## 2. ตอบคำถามที่สองก่อน เพราะมันไม่ใช่บั๊ก

**ส่วนที่ย้อนแย้งจนงงได้จริงคือ `admin` เป็นบทบาทเดียวที่เซ็นขั้นหัวหน้าแทนได้**

## 3. คำถามแรกเป็นเรื่องของจอ และเป็นสิ่งที่ต้องแก้

สิ่งที่ตอบอยู่ตรงนั้นคือขีด `—` กว้าง 32px (`WatchMark` + `.act-none`) เหนือ 861px
`.own-note` ถูกซ่อนเพื่อคืนความกว้างให้คอลัมน์ที่เหลือ 96px ประโยคบอกเหตุจึงเหลือ
อยู่แต่ในทูลทิป **และทูลทิปพูดกับเมาส์ที่มาหยุดนิ่งเท่านั้น**

เหตุผลที่เคยเขียนกันไว้ข้างขีด (2026-09-11) คือ

> *a row at this step that is not this reader's to sign never will [get the
> buttons], so it keeps the dash rather than a promise the screen cannot keep*

**เหตุผลนั้นเป็นเรื่องความซื่อตรงของจอ และมันแลกมาด้วยคำตอบของคนอ่าน** ปุ่มคู่ที่
เทาไม่ใช่คำสัญญา มันคือรูปร่างของการตัดสินที่หายไป ซึ่งคือสิ่งที่คนกำลังหาปุ่มมองหา

## 4. คำถามที่ถามกลับ และคำตอบ

| ถาม | ตอบ |
|---|---|
| ให้ปุ่มคู่ที่ disable แทนขีดตรงไหนบ้าง — เฉพาะแถวที่เจอ หรือทุกแถวที่เป็นขีด | **ทุกแถวที่ตอนนี้เป็นขีด** |
| หน้าต่างรายละเอียดที่เปิดจากแถว (ตอนนี้ยังโชว์ปุ่มกดได้จริง) ให้เป็นแบบไหน | **ปุ่มคู่ที่ disable ไว้ เหมือนแถว** |

คำสั่งเดิมจากผู้ใช้: *ตามเงื่อนไขเดิมไงครับ ปุ่มขึ้นแต่ disable ไว้*

## 5. รูที่เจอระหว่างไล่โค้ด — และเป็นเหตุผลที่งานนี้ไม่ใช่แค่เรื่องหน้าตา

`DetailModal` รับพร็อพ `mine` (= `barredAsOwnFiling`) กับ `watching`
(= `!signableHere`) **ซึ่งครอบเหตุผลสองในสามข้อ** · ใบที่คนอ่านเป็นผู้เซ็นขั้น
หัวหน้าเองไม่เข้าข่ายทั้งคู่ ท้ายกล่องจึงตกไปที่สาขา "วาดปุ่มจริง"

**แถวซ่อนปุ่ม แล้วกดที่แถวเพื่อเปิดกล่อง ปุ่มกลับมาครบและกดได้** กดแล้วเดินทางไปหา
409 ที่ `approvalPermission` · ช่องติ๊กกับ `actionable` ถามครบมาตลอด กล่องเป็น
ประตูเดียวที่ไม่ได้ถาม

## 6. สิ่งที่ลงมือ

- **`WatchMark` และกฎ `.act-none` ถูกถอดทั้งคู่** พร้อม
  `.queue-table td.act-col .act-none { display: none; }` ในบล็อก 860px
- **`awaitingEarlierStep` ถูกถอด** เหลือกรณีเดียว ไม่ต้องเลือก
- **สามสาขาที่ไม่มีปุ่มใช้ `WatchActions` เหมือนกันหมด** — และ `.act-watch`
  ไม่ต้องแก้ CSS เลย เพราะ 70px ถูกวัดไว้กับคอลัมน์ 96px ตั้งแต่ต้น
- **ประโยคเหลือแหล่งเดียวต่อเหตุผล** `watchingNote` (ของเดิม) · `SIGNED_MGR_NOTE`
  · `ownFilingNote(entry)` — รูปร่างเดียวกันทั้งสาม (`short` / `head` / `body`)
  ก่อนหน้านี้ประโยคเดียวกันถูกพิมพ์สี่ที่และเพี้ยนกันไปแล้วสามสำนวน
- **`blockedNote(e)`** ตอบข้อเดียวว่า "ทำไมแถวนี้ไม่มีการตัดสิน หรือ `null`" ·
  ถาม `signableHere` เป็นบรรทัดแรก ประตูทั้งสี่จึงยังตอบจากกฎเดียว
- **ป๊อปอัปเหลือพร็อพเดียว `blocked`** แทน `mine` + `watching` + `watchNote` ·
  ท้ายกล่องวาดปุ่มคู่ที่ปิดไว้ในกรอบ `.foot-split` ที่ถือทูลทิป และบรรทัดแรกของ
  เนื้อกล่องพูดครบทั้งสามเหตุผล
- **`approveLabel`** เป็นค่าเดียวของสองปุ่ม

## 7. ทางที่ไม่ได้เลือก

- **ไม่แก้กฎ §6 ให้ admin ข้ามได้** — คำถามคือ "ทำไมกดไม่ได้" ไม่ใช่ "ขอให้กดได้"
  และกฎนี้คือสิ่งที่ทำให้ลายเซ็นสองอันเป็นคนสองคนจริง
- **ไม่เลือกทางที่แค่โชว์ `.own-note` บนเดสก์ท็อป** — คอลัมน์ 96px ไม่มีที่ให้
  ประโยค และการขยายคอลัมน์คือการเอาความกว้างคืนไปจากอีกสิบเอ็ดคอลัมน์
- **ไม่ให้ป๊อปอัปซ่อนปุ่มเหมือนเดิม** — ถามแล้ว ได้คำตอบว่าให้เหมือนแถว
- **ไม่ทำ `blockedNote` เป็นฟังก์ชันระดับโมดูล** — มันต้องใช้ `signableHere`
  ซึ่งปิดทับ `stage` / `user` / `isHr` การย้ายออกไปคือการเขียนกฎนั้นซ้ำ
