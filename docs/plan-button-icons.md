# plan-button-icons.md — ไอคอนบนปุ่มทั้งแอป และการกระชับป้ายคำ

**สถานะ: รออนุมัติ §3 และ §4** · เขียน 2026-09-11

สิ่งที่ผู้ใช้ตัดสินไปแล้วในวันเดียวกัน และแผนนี้ไม่ถามซ้ำ:

- ขอบเขตคือปุ่ม `.btn` และ `.link` เท่านั้น (§2)
- **ไอคอนเอามาจาก `lucide-react` ไม่วาด SVG เอง**
- **`Icon` ห่อ lucide ไว้** — ทั้งแอปยังเขียน `<Icon name="download" />` เหมือนเดิม
- **ไอคอนเดิม 21 ตัวที่วาดมือไว้ ย้ายไป lucide ให้หมด** ไม่เหลือสองชุดในแอปเดียว
- ทุกปุ่มยังต้องมีคำ ไม่มีปุ่มไอคอนเปล่า (§4)
- ส่งงานเป็นเฟสต่อไฟล์ (§6)

## 3. ไอคอน — `lucide-react` ทั้งชุด

### 3.1 ทำไม lucide และมันเข้ากับของเดิมตรงไหน

`lucide-react@1.44.0` · MIT · peer dependency รับ React 19 ที่แอปนี้ใช้อยู่ ·
ตอนนี้แอปมี dependency แค่ 7 ตัว นี่จะเป็นตัวที่ 8

แนวการวาดของ lucide ตรงกับกฎที่ `components/icons.jsx` เขียนไว้เองแทบทุกข้อ —
กล่อง 24 หน่วย · เส้นไม่ใช่พื้นทึบ · `currentColor` · ปลายมนและมุมมน ·
ไม่มีตัวอักษรในรูป ต่างกันข้อเดียวคือความหนาเส้น lucide ตั้งต้นที่ 2 ส่วนแอปนี้
ใช้ 1.75 — ส่งเป็น prop ได้ จึงไม่ต้องยอมตามค่า default

### 3.2 รูปร่างใหม่ของ `components/icons.jsx`

ไฟล์ยังอยู่ ยังส่งออก `Icon` กับ `ICON_NAMES` เหมือนเดิม และยังมีตาราง
`const ICONS = { … }` หน้าตาเดิม เปลี่ยนแค่ว่าค่าในตารางเป็นคอมโพเนนต์ของ lucide
แทนที่จะเป็น `<path>` ที่เขียนมือ:

```jsx
import { Clock, Inbox, Users, Download, … } from 'lucide-react';

const ICONS = {
  clock: Clock,
  inbox: Inbox,
  download: Download,
  …
};

export default function Icon({ name, className = '' }) {
  const Glyph = ICONS[name];
  if (!Glyph) return null;
  return (
    <Glyph className={className} strokeWidth={1.75} aria-hidden="true" focusable="false" />
  );
}

export const ICON_NAMES = Object.keys(ICONS);
```

สามอย่างที่ตัวห่อต้องทำต่อ ห้ามปล่อยให้เป็นค่า default ของ lucide:

- **`strokeWidth={1.75}`** — ไม่ใช่ 2 เส้น 2 หนากว่าของเดิมพอให้ไอคอน 15px ใน
  ปุ่มดูหนักกว่าตัวหนังสือข้าง ๆ
- **`aria-hidden` กับ `focusable`** — lucide ไม่ใส่ให้ ตัวห่อเดิมใส่อยู่แล้วและ
  ต้องใส่ต่อ คำบนปุ่มคือชื่อของปุ่ม ไอคอนต้องไม่ถูกอ่านซ้ำ
- **ขนาดมาจาก CSS ไม่ใช่ prop** — lucide เขียน `width="24" height="24"` ลงแท็ก
  แต่ `.btn-icon` ใน `app/styles.css` บังคับ 15px อยู่แล้วและกฎ CSS ชนะ attribute
  เสมอ จึงไม่ต้องส่ง `size` และไม่ควรส่ง เพราะจะกลายเป็นขนาดสองที่

### 3.4 สามอย่างที่จะเสียไป และต้องดูของจริงก่อนรับ

การย้ายไป lucide **ไม่ใช่การแลกที่ฟรี** คอมเมนต์ในไฟล์เดิมอธิบายเหตุผลของการวาด
สามตัวนี้ไว้ยาว และเหตุผลนั้นจะไม่มีผลอีกต่อไป:

1. **`printer` เสียลูกเล่นที่ทำให้มันอ่านออกที่ 15px** — ของเดิมวาดกระดาษที่
   ออกมาจากเครื่องทับตัวเครื่อง แล้วเติมพื้นด้วย `var(--card)` เพื่อไม่ให้เส้น
   สองชั้นซ้อนกันเป็นรอยเปื้อน เป็นไอคอนตัวเดียวในไฟล์ที่เติมพื้น และเติมด้วย
   โทเคนเพื่อให้รอดในธีมมืด **lucide ไม่ทำแบบนี้** ต้องดูที่ 15px ทั้งสองธีมจริง ๆ
   ก่อนบอกว่าใช้ได้
2. **`pencil` เสียข้อโต้แย้งเรื่องสองเส้นไม่ใช่สามเส้น** — ของเดิมตัดเส้นที่สาม
   ออกเพราะที่ 15px มันตกลงมาทับเส้นที่สองภายในพิกเซลเดียว ต้องดูของ lucide ที่
   ขนาดจริงว่าอาการเดิมกลับมาไหม
3. **คอมเมนต์รายตัวในไฟล์จะกลายเป็นคำอธิบายของรูปที่ไม่มีอยู่แล้ว** — ต้องเขียนใหม่
   ให้ตอบคำถามใหม่ คือ *ทำไมเลือก lucide ตัวนี้* ไม่ใช่ *ทำไมพิกัดเส้นเป็นแบบนี้* ·
   ส่วนหัวไฟล์ที่อธิบายว่าทำไมถึงเลิกใช้อักขระ `◧ ◔ ◕ ▤ ▥` **ยังจริงและต้องอยู่ต่อ**
   มันคือเหตุผลที่งานทั้งแผนนี้มีอยู่

### 3.6 ไอคอนตัวเดียวสองความหมาย — เรื่องที่ต้องตัดสิน

`cross` ตอนนี้แปลว่า *ไม่อนุมัติ* (คู่กับ `tick` ในคอลัมน์ปุ่มของคิว) ถ้าเอาไปใช้
กับ *ยกเลิก* และ *ปิด* ด้วย ไอคอนตัวเดียวจะมีสองความหมาย — ความหมายหนึ่งคือ
การตัดสินใจที่มีผลกับใบ OT อีกความหมายคือการเดินออกจากหน้าต่างโดยไม่ทำอะไร

**ผมแนะนำให้ใช้ `cross` ทั้งสองความหมาย** — สีเป็นตัวแยกอยู่แล้ว (ปุ่ม ghost เทา
กับ ghost danger แดง) และป้ายคำก็ยังอยู่ครบตาม §4 · ทางเลือกอีกทางคือเพิ่ม
`CircleX` เป็นไอคอนตัวที่ 20 สำหรับ *ไม่อนุมัติ* แล้วปล่อย `X` เปล่าให้ *ยกเลิก/ปิด*
ซึ่งแยกชัดกว่าแต่แลกด้วยการแก้ `test/hrMonthCards.test.js` ที่ตรึงชื่อ `cross` ไว้

### 3.7 ขั้นตอนอนุมัติรูป

ติดตั้ง lucide แล้วเขียน `components/icons.jsx` ใหม่ก่อน จากนั้นเพิ่มตารางแสดง
ไอคอนทั้ง 40 ตัวในหน้า **คู่มือ** (`components/ManualView.jsx` มีโครงตารางไอคอน
อยู่แล้วที่คลาส `manual-sec-icon`) เพื่อดูของจริงทั้งสองธีมที่ขนาดจริง 15px —
โดยเฉพาะ `printer` กับ `pencil` ใน §3.4 · **นี่คือปลายเฟส 0 และเป็นจุดหยุด
รออนุมัติ ยังไม่แตะปุ่มใบไหนทั้งสิ้น**

## 4. คำบนปุ่ม — สั้นลง แต่ยังมีคำเสมอ

**ห้ามมีปุ่มไอคอนเปล่า** ในขอบเขตนี้ ไอคอนมาเพิ่ม ไม่ใช่มาแทน

กฎที่ใช้ตัด เรียงตามลำดับ:

1. **ตัดคำที่ไอคอนพูดแทนได้จริง** — *ดาวน์โหลด* ออกเมื่อมีลูกศรลง · *ดู* ออกเมื่อ
   มีดวงตา · `+` ออกเมื่อมีเครื่องหมายบวกเป็นรูป
2. **ตัดคำที่บริบทพูดอยู่แล้ว** — ปุ่มในโมดัล *รีเซ็ตรหัสผ่าน* ไม่ต้องพูดว่า
   รหัสผ่าน หัวโมดัลพูดไปแล้ว
3. **ห้ามตัดจนเหลือคำที่มีสองความหมายบนจอเดียวกัน** — *ถอน* เดี่ยว ๆ บนจอที่มี
   ทั้งถอนใบและถอนคำขอ ไม่ผ่าน
4. **จำนวนที่เป็นศูนย์ห้ามขึ้นปุ่ม** — กฎเดิมใน `docs/design.md` §5 ไม่เปลี่ยน
5. **ป้ายตอนกำลังทำงานสั้นตามตัวปุ่ม** — *กำลังบันทึก…* อยู่ต่อได้ แต่ถ้าตัวปุ่ม
   สั้นลงแล้ว ป้ายตอนกำลังทำก็สั้นตาม

## 5. กลไก — CSS และกฎการวาง

### 5.1 ปุ่ม `.btn` ใช้ของเดิมทั้งหมด ไม่ต้องเพิ่มอะไร

`app/styles.css` มีอยู่แล้ว และตอนนี้ใช้จริงเพียง 6 จุด:

```css
.btn.with-icon { display: inline-flex; align-items: center; justify-content: center; gap: 6px; }
.btn.with-icon .btn-icon { width: 15px; height: 15px; flex: none; }
```

รูปแบบที่ทุกปุ่มจะเขียนเหมือนกันหมด — **ไอคอนอยู่ซ้ายของคำเสมอ ไม่มีข้อยกเว้น**:

```jsx
<button className="btn ghost sm with-icon" onClick={…}>
  <Icon name="download" className="btn-icon" /> แม่แบบ CSV
</button>
```

### 5.2 ปุ่ม `.link` ต้องมีกฎใหม่ — สองบรรทัด

`.link` เป็นตัวอักษร 13px ที่ไม่มี flex เลย ไอคอน 15px จะสูงกว่าตัวอักษรและ
ดันเส้นฐาน ต้องเพิ่ม:

```css
.link.with-icon { display: inline-flex; align-items: center; gap: 5px; vertical-align: middle; }
.link.with-icon .btn-icon { width: 13px; height: 13px; flex: none; }
```

13px ไม่ใช่ 15px เพราะตัวอักษรของ `.link` เล็กกว่าตัวอักษรของ `.btn`

### 5.3 ลูกศรที่หมุน — ไม่ใช้ไอคอนตัวที่สอง

`chevronDown` ตัวเดียวรับใช้ทั้ง *กาง* และ *หุบ* หมุนด้วย CSS:

```css
.btn.with-icon.is-open .btn-icon { transform: rotate(180deg); }
```

ไม่ใส่ transition บนตัวนี้ — `docs/design.md` §7 มีรายการห้ามเรื่องการเคลื่อนไหว
ที่ไม่มีใครขอ

### 5.4 ปุ่มในคอลัมน์ตาราง — กฎเดิมยังบังคับ

`docs/design.md` §5: ปุ่มในคอลัมน์ของตารางชิดขวาเสมอผ่านคลาส `row-actions` และ
ปุ่มที่กดไม่ได้ต้อง disable ไว้พร้อม `title` ไม่ใช่หายไป **การเพิ่มไอคอนทำให้ปุ่ม
กว้างขึ้นราว 20px ต่อใบ** คอลัมน์ปุ่มของ `components/AdminView.jsx` ที่มีสามปุ่ม
เรียงกัน (`act-main` · `act-security` · `act-info`) จะกว้างขึ้นราว 60px — นี่คือ
เหตุผลที่ §4.1 ตัดคำของสามใบนั้นด้วย และเป็นจุดที่ต้องวัดที่ 1024 และ 861 ก่อน
บอกว่าเสร็จ

## 9. สิ่งที่แผนนี้เลือกจะไม่ทำ

- **ไม่สร้างดีไซน์ซิสเต็มใหม่** — `docs/design.md` กับ `docs/plan-design-system.md`
  เขียนไว้ชัดว่าของที่มีอยู่แล้วคือของจริง งานนี้คือเอากฎเดิมไปใช้ให้ครบ
- **ไม่แตะ modal-x · alert-x · searchbox-clear · fold-pill · alert-fold** รอบนี้
  — แต่บันทึกไว้ที่ §2 ว่าเป็นปัญหาเดียวกันและควรเป็นแผนถัดไป
- **ไม่ import จาก `lucide-react` ตรง ๆ ในคอมโพเนนต์ใดทั้งสิ้น** — ทุกไอคอนผ่าน
  `Icon` เสมอ เพื่อให้ความหนาเส้น ขนาด และ `aria-hidden` ถูกกำหนดที่เดียว และ
  เพื่อให้วันที่ต้องเปลี่ยน lib อีกครั้ง แก้ไฟล์เดียวจบ
- **ไม่มีไอคอนเซ็ตที่สอง ไม่ใช้ไอคอนฟอนต์ ไม่ใช้อีโมจิ** — `components/icons.jsx`
  คือชุดเดียวของแอปนี้ และหลังงานนี้มันคือ lucide ล้วน
- **ไม่ทำปุ่มไอคอนเปล่า** — ตัดสินไว้แล้วใน §4
