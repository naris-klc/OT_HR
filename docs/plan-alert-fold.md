# แผน — ข้อความแจ้งเตือนหน้าแรก พับเหลือแถวเดียว กดเพื่อกาง

สั่งไว้ 2026-09-15 พร้อมภาพหน้าจอมือถือ: กล่องแจ้งเตือนสามใบเรียงกันบนหน้าแรก
กินพื้นที่เกือบทั้งจอก่อนถึงงานจริง — *"อยากให้แสดงตัดซ่อนไว้เป็นแถวเดียว แต่กด
เพื่อขยายได้"*

## สิ่งที่ตกลงกับผู้ใช้แล้ว

| คำถาม | คำตอบ |
| --- | --- |
| พับใบไหน | ทั้งสามใบ — สำรองข้อมูล · รหัสผ่านที่ฝ่ายบุคคลตั้งให้ · ประกาศวันหยุด |
| พับแล้วเหลืออะไร | ประโยคเดิมทั้งประโยค ตัดท้ายด้วย … ที่ขอบขวาของแถวแรก |
| ปุ่มข้างในกล่อง | ซ่อนไปกับเนื้อหา (เปลี่ยนรหัสผ่าน · ดูปฏิทินวันหยุดประจำปี) |
| จำสถานะไหม | ไม่จำ — เข้าหน้าใหม่พับเสมอ |
| สัญญาณว่ากดได้ | ลูกศร ▼/▲ มุมขวา ใช้ `.alert-fold` ของเดิม |
| ความกว้างไหน | ทุกความกว้าง ไม่ผูกกับ breakpoint |

## เรื่องที่ต้องบอกก่อน

**กฎเดิมของโปรเจกต์ห้ามพับ alert** — `test/disclosure.test.js` เขียนไว้ว่า
*"alert ถูกอ่านตอนที่มันขึ้น ไม่งั้นไม่ถูกอ่าน"* และมี `ALERTS_THAT_MAY_FOLD`
เป็นรายชื่อข้อยกเว้นที่อนุญาตให้พับ **เฉพาะครึ่งที่ไม่ใช่ตัวเตือน** งานนี้พับทั้ง
กล่อง จึงเป็นการเปลี่ยนกฎ ไม่ใช่การเพิ่มชื่อลงรายการ — เหตุผลที่รับได้คือ
**ประโยคเตือนยังอยู่บนจอเสมอ** ต่างจากการซ่อนทั้งใบ สิ่งที่หายไปคือรายละเอียด
ท้ายประโยค ซึ่งคนอ่านเห็น … ว่ายังมีต่อ

`HolidayBanner` เพิ่งถอด fold ออกเมื่อ 2026-09-11 (เก็บสถานะใน
`ot-holiday-fold`) เพราะย่อเหลือแถวเดียวได้แล้ว งานนี้ใส่ fold กลับ — แต่**ไม่**
เอาการจำสถานะกลับมา ตามที่ผู้ใช้ตอบ เหตุผลเดิมที่ถอดไปยังยืน: ประกาศที่คนกด
ปิดครั้งเดียวแล้วหายตลอดไปคือประกาศที่ไม่ได้ประกาศ

**ลูกศรขึ้นเมื่อมีของให้ซ่อนจริงเท่านั้น** — วัดจากของจริงว่าข้อความล้นแถวแรกไหม
(`scrollWidth > clientWidth` + `ResizeObserver`) หรือกล่องนั้นมีปุ่มข้างใน ถ้า
จอกว้างพอจนประโยคจบในแถวเดียวและไม่มีปุ่ม กล่องนั้นไม่มีลูกศรและพับไม่ได้ —
ปุ่มที่กดแล้วไม่มีอะไรเกิดขึ้นคือปุ่มที่ไม่ควรมี (กฎเดียวกับ `Disclosure`)

## จะเขียนอะไร

### 1. `components/common.jsx` — ของใหม่ชิ้นเดียว ใช้ร่วมสามที่

`useOneLine({ hasActions })` — hook คืน `{ open, toggle, foldable, ref, arrow }`

- `ref` ผูกกับ element ที่ถือข้อความ วัดล้นด้วย `ResizeObserver` หยุดวัดตอนกาง
  (เหตุผลเดียวกับ `Disclosure`: ตอนกางไม่มีอะไรล้น ถ้าวัดต่อ ลูกศรจะหายกลางมือ)
- `foldable` = ล้น หรือมีปุ่มข้างใน
- `arrow` = ปุ่ม `.alert-fold` ▼/▲ พร้อม `aria-expanded` / `aria-controls`

`AlertFold` — ห่อ `Alert` ให้ใช้ hook นี้ รับ `actions` แยกจาก `children`
กดที่กล่องตอนพับเพื่อกาง กดที่แถวข้อความตอนกางเพื่อพับ — `foldClick` ของเดิม

### 2. `app/styles.css`

`.one-line` — `white-space: nowrap; overflow: hidden; text-overflow: ellipsis`
บนตัวถือข้อความ ใช้กับทั้ง `.alert` และ `.announce`

ไม่ใช้ `-webkit-line-clamp` เพราะแถวเดียวมีเครื่องมือตรงกว่า และ
`test/disclosure.test.js` นับจำนวนครั้งที่ไฟล์นี้เอ่ยถึง clamp ไว้เป็นกำแพง

พิมพ์ (`@media print`) — คลาย `.one-line` เหมือนที่ทำกับ clamp: กระดาษไม่มี
ลูกศรให้กด

### 3. สามที่ใช้งาน

- `components/BackupBanner.jsx` — เปลี่ยน `Alert` เป็น `AlertFold` ไม่มีปุ่ม
- `components/App.jsx` `PasswordReminder` — ปุ่ม เปลี่ยนรหัสผ่าน ย้ายไป `actions`
- `components/HolidayBanner.jsx` — `.announce` ไม่ใช่ `.alert` จึงใช้ hook ตรงๆ
  ปุ่ม ดูปฏิทินวันหยุดประจำปี เป็น `actions`

### 4. เทสต์กับเอกสาร

- `test/disclosure.test.js` — แก้กฎ "alert ห้ามพับ" ให้ตรงกับที่ตกลงใหม่ และ
  พินว่าพับได้สามใบไหน
- เทสต์ใหม่: พับแล้วประโยคยังอยู่ใน DOM · ปุ่มข้างในหายตอนพับ · ไม่มี
  `localStorage` ในทางนี้
- `docs/design.md`, `README.md`, `docs/features.md` — หาแล้วแก้ย่อหน้าที่บรรยาย
  กล่องสามใบนี้ในคอมมิตเดียวกัน
