## แก้แล้ว

1. **`body()` คืน `null` ได้** — JSON `null` `"str"` `[]` ผ่าน `JSON.parse` แล้ว
   ทุก route ที่ destructure ตรง ๆ ตอบ 500: login, เปลี่ยนรหัสผ่าน, PATCH settings,
   preview · แก้ที่ `lib/http.js` จุดเดียว คืน `{}` เมื่อไม่ใช่ object
2. **ไล่หารหัสพนักงานได้จากเวลาตอบ login** — รหัสที่ไม่มีหรือบัญชีที่ปิดใช้งานข้าม
   bcrypt: median 4 ms เทียบกับ 91 ms สองกลุ่มไม่ซ้อนกันเลย (28 ครั้งต่อกลุ่ม) ·
   แก้ให้เทียบกับ hash ตัวหลอกที่สร้างด้วย `hashPassword` ตัวเดียวกัน · หลังแก้
   59.1 กับ 58.3 ms ซ้อนกัน · สำคัญกว่าที่ดูเพราะรหัสผ่านแรกเข้าคือรหัสพนักงาน
   และ throttle นับต่อรหัส ไม่ใช่ต่อ IP (ข้อ 1.1 ของ QA 2026-09-21)
3. **รหัสพนักงานยาวมากทำให้ login ตอบ 500** — `codeMatcher` สร้าง regex ยาวเกินที่
   Mongo รับ · รหัสเกิน 64 ตัวไม่ถูกส่งไปค้น
4. **หน้าเลื่อนแนวนอนที่ 861–925px** (ตั้งค่าระบบ ของ HR/admin) — คำที่พับไว้ใน
   ปุ่ม `RowAction` เป็น `position: absolute` แต่ยึดกับกล่องนอก `.table-wrap`
   จึงไม่ถูกตัด ดันหน้ากว้างเกินจอ 88px · แก้ด้วย `position: relative` บน
   `.btn.act-icon` · sweep ซ้ำแล้วไม่มีหน้าไหนเลื่อนแนวนอนที่ความกว้างไหนเลย

เทสต์: `test/requestInputGuards.test.js` (ข้อ 1–3) · `test/hrMonthCards.test.js` (ข้อ 4)

## รอผู้ใช้ตัดสิน — เปลี่ยนหน้าตา จึงไม่ได้แก้เอง (รายการเดิมรอบแรก)

5. **ช่องกรอกบนจอ ≤ 640px เป็น 15px** — `docs/design.md` §6 และ §6.1 บอกว่าต้อง
   ≥ 16px (ต่ำกว่านั้น iOS ซูมทั้งชีตตอนโฟกัส) แต่กฎนี้มีจริงแค่ `.cal-type-in`

   คิวอนุมัติ ตรวจสอบประจำเดือน ตั้งค่าระบบ
6. **`--muted-2` บนพื้นขาว 3.41 (ไม่ผ่าน AA)** — รู้แล้วตั้งแต่ 2026-08-28

8. **กล่องเลื่อนแนวนอนที่คีย์บอร์ดเข้าไม่ถึง** — `.f027-screen` (390px),
   `.table-wrap` ของรายงานการเงิน (390px), `.log-tally-view ul` · ทางแก้ปกติคือ
   `tabIndex={0}` + ชื่อ ซึ่งเพิ่มจุดโฟกัส (และวงแหวน) ในลำดับ Tab
