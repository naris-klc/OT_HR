## 1. สิ่งที่ต้องรู้ก่อนลงมือ

### ฟิลด์เดียว ที่ลากอะไรไปด้วยเยอะมาก

`endsNextDay` ไม่ได้เป็นแค่ป้าย มันเป็นแกนที่ทำให้ทั้งระบบต้องคิดแบบ *สองวัน*:

| ที่ | ทำอะไรเพราะข้ามคืน |
|---|---|
| `src/lib/otEngine.js` | บวก 1440 นาที · ตัดกะที่เที่ยงคืน · `dayIndex` · ปลายกะพิมพ์ `24:00` · `TOO_LONG` |
| `src/lib/otEngine.js` `sessionDates` | คืนสองวันที่ ให้ `resolveDayTypes` ไปหาว่าวันไหนเป็นวันหยุด |
| `src/lib/otEngine.js` `lunchWindows` | คาบเกี่ยวพักเที่ยงได้สองครั้ง → `breakPerCalendarDay` ([OPEN 2]) |
| `lib/caps.js` `weeksOfEntry` | แยกครึ่งกะเข้าสองสัปดาห์ |
| `lib/overlap.js` | `findOverlaps` มีอยู่เพื่อจับคู่ที่ข้ามเที่ยงคืนโดยเฉพาะ |
| `lib/scanMatch.js` | สแกนเช้าวันถัดไปติดป้าย `(+1)` · `minutesFrom` ทำเส้นตัวเลขเส้นเดียว |
| `lib/scanMatchQuery.js` | ดึงสแกน **หนึ่งวันทั้งสองข้าง** ของช่วง |
| `lib/holidays.js` `previousDay` | เพิ่มวันหยุดแล้วต้องคิดใบของ *วันก่อนหน้า* ใหม่ด้วย |
| `lib/reports.js` `latestPerSession` | `endsNextDay` เป็นส่วนหนึ่งของ key |

### ข้อมูลจริงในฐาน

`mongodb://127.0.0.1:27018/primus_ot` · `otentries` **422 ใบ** มี
`endsNextDay: true` **ใบเดียว**:

```
_id 6a9faedf07b147c3cb7b62a3 · workDate 2026-09-09 · 21:00–21:00 · pending_mgr
```

21:00–21:00 คือกะ 24 ชั่วโมงพอดี (`endsNextDayFor` ตอบ `true` เพราะเทียบด้วย `<=`)
ซึ่งเป็นค่าที่เอนจินยอมรับแบบเฉียดฉิว **ใบนี้จะคำนวณใหม่ไม่ได้หลังถอนฟีเจอร์**
เพราะเวลาสิ้นสุดไม่ได้อยู่หลังเวลาเริ่ม

### `findOverlaps` — เก็บไว้ ไม่ลบ

ไฟล์ `lib/overlap.js` บอกเองว่า *"คู่เดียวที่มันยังจับได้คือคู่ที่ข้ามเที่ยงคืน"*
พอข้ามคืนหายไป `findSameDate` (หนึ่งวัน หนึ่งใบ) ก็ครอบคลุมทุกกรณีแล้ว
**แต่ยังไม่ลบ `findOverlaps`** — มันเป็นตาข่ายชั้นที่สองที่ไม่ได้เสียหายอะไร
และการลบมันคือการถอนกฎ *เวลาทับซ้อน* ซึ่งไม่ใช่สิ่งที่ HR สั่ง เปลี่ยนแค่
`sessionWindow` ให้เลิกบวกวัน และเขียนเหตุผลในหัวไฟล์ใหม่ให้ตรงความจริง

## 3. สิ่งที่จะเสียไป พูดตรง ๆ

- **กะข้ามคืนยื่นไม่ได้อีก** ใครทำ 17:00–02:00 ต้องแยกสองใบ ซึ่งชนกฎ
  *หนึ่งวัน หนึ่งใบ* ไหม — ไม่ชน เพราะเป็นคนละวันที่
- **ใบเดิม 1 ใบในฐานจะคำนวณใหม่ไม่ได้** ต้องให้คนแก้เวลาหรือยกเลิก
- **`breakPerCalendarDay` หายไปจากหน้าตั้งค่า** ค่าที่ HR เคยตั้งไว้จะไม่ถูกอ่าน
  อีก (มันไม่มีผลอยู่แล้วถ้าไม่มีกะข้ามวัน)
- **เพิ่มวันหยุดแล้วคิดใบของวันก่อนหน้าใหม่ — เลิกทำ** ไม่มีใบไหนล้นข้ามวันแล้ว
